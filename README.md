# Eizora Labs Website

The official website for Eizora Labs, an independent digital commerce and technology studio.

## Stack

- Next.js 15
- React 19
- JavaScript
- Tailwind CSS 3

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the site.

## Notes

- Concept work shown in the Selected Work section is explicitly illustrative.
- Add the studio's confirmed contact email before launch.
- Review all copy, links, and metadata before connecting the production domain.
